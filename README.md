# Learn Penang Hokkien

Speaking trainer for Penang Hokkien (also close to Medan Hokkien). Installable app (PWA) that works offline.

- Daily routine: learn and shadow new phrases, then review all earlier phrases by speaking
- Spelling: Taiji Romanisation (the Penang Hokkien Dictionary system), tone numbers after each syllable
- Languages: EN / ID / MS
- Recordings stay on your own device

Live: https://iggifernandes.github.io/Learn-Penang-Hokkien/
